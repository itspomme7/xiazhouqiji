# H1 生产权限检查清单（不自动部署）

本文件只用于上线前人工核对。仓库代码不会修改生产数据库、云存储规则或云函数配置。

## 数据库 `notes`

- 在云开发控制台确认客户端权限为“仅管理端可读写”或等效的自定义拒绝规则。
- 使用访客微信号在测试环境直接执行 `wx.cloud.database().collection('notes').get()`，预期为权限拒绝。
- 使用访客微信号按已知草稿 `_id` 直接读取，预期为权限拒绝。
- 确认 `notesApi` 云函数仍能读取公开笔记，管理员仍能读写草稿。

建议目标规则：客户端 `read=false`、`write=false`；公开内容也统一通过 `notesApi` 返回。具体规则语法应先在测试环境按当前 CloudBase 控制台版本验证。

## 云存储

- 确认不是默认“所有用户可读”。
- 建议客户端读取和写入均拒绝；云函数管理端继续上传原图并签发短期 URL。
- 使用访客微信号对一个专用测试草稿的已知 `fileID` 调用 `wx.cloud.downloadFile`，预期为权限拒绝。
- 确认访客仍可通过已发布笔记详情接口返回的短期 URL 查看公开图片。
- 确认管理员完整备份仍可由云函数取得临时 URL、下载并通过 SHA256 校验。
- 修改规则后等待平台规则生效，再清除小程序缓存重新测试。

建议目标规则（示意，部署前必须在测试环境校验语法）：

```json
{
  "read": "false",
  "write": "false"
}
```

## 云函数与日志

- `ADMIN_OPENID` 只配置在云函数环境变量，不写入仓库或日志。
- 用访客账号逐一调用 `save`、`delete`、`uploadImage`、`backupManifestStart`、`backupImage`、`restoreNote`，预期全部拒绝。
- 检查日志不输出完整事件、Base64、临时下载 URL、OpenID 或私人正文。
- 检查 `notesApi` 超时配置足以完成 2MB 图片合并和最多 500 篇清单事务；先在测试环境压测，不直接改生产。

## 上线判定

只有以下项目全部有测试环境证据后，才建议复制规则到生产：

1. 访客无法直接读取数据库草稿。
2. 访客持有草稿 `fileID` 也无法直接下载。
3. 已发布图片通过短期 URL 正常显示。
4. 管理员编辑、备份和恢复在测试环境通过。
5. 规则回滚方案和变更前截图已保存。
