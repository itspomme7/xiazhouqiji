# 下周七集 · Xiazhouqiji

微信原生小程序（Java 学习笔记与图文资料整理），使用微信云开发 CloudBase。

> **当前状态：V1.0.0 上线候选 / 待审查。** 已完成基础笔记、代码块、图片、管理员与访客权限的实际测试；**云端完整图文备份与恢复仍需进一步审查和真机验收**。尚未通过正式版本审核。

## 项目目标
- 管理员创建文字、Java 代码与图片混排的云端笔记，管理公开笔记和私人草稿。
- 访客只读已发布内容，不能读取草稿或编辑、上传、删除。
- 保留稳定的奶白、灰绿、适配 iPhone 的简洁视觉。
- 支持可移植的完整图文备份和恢复，必须防止丢数据、超限和重复导入。

## 项目目录（源码上传后）
```text
pages/                 页面
components/tabbar/     底部导航
utils/                 数据与备份
cloudfunctions/login/  微信身份识别
cloudfunctions/notesApi/ 笔记 API、备份与恢复
assets/                小程序图片资源
tests/                 本地自动化测试
```

## Codex 协作
先阅读 [AGENTS.md](./AGENTS.md)，**第一项任务为只读代码审查**，重点排查备份/恢复涉及的云函数单次响应上限（1MB）、图片读写权限、分块传输、失败与重复恢复。未经用户批准不要部署云函数、修改生产数据库或发布小程序。

## 安全
此仓库为**公开仓库**。不要提交 `project.private.config.json`、`.env`、真实 OpenID/ADMIN_OPENID 值、云服务密钥、笔记导出 JSON 或任何私人信息。云环境 ID 和小程序 AppID 本身不是密钥，但生产凭据必须只留在云端配置。
